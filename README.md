# 🥊 LOK SABHA KOMBAT 7: Khela Hobe Edition (3D Tekken WebGL Game)

A stylized 3D **Tekken 7**-inspired fighting game built with **Three.js (WebGL)**, **TypeScript**, **Vite**, and a **Procedural Web Audio Synthesizer**, starring **Narendra Modi** (*"MITRON!"*), **Mamata Banerjee** (*"KHELA HOBE!"*), **Arvind Kejriwal**, and **Rahul Gandhi**.

---

## 🔥 Features

- **4 Articulated 3D Caricature Fighters**:
  - **Narendra Modi (*56-Inch Saffron Supreme*)**: Saffron Nehru jacket, white beard, rimless spectacles, and Golden Lotus Microphone.
  - **Mamata Banerjee (*Royal Bengal Hurricane*)**: White Tant Saree with Blue Border Pallu, Jura bun, spectacles, and Flying Hawai Chappal.
  - **Arvind Kejriwal (*Muffler-Man Broom Master*)**: Maroon winter muffler ear-wrap, white Gandhi Topi, and Aam Aadmi Jhadu (Broom).
  - **Rahul Gandhi (*Bharat Jodo Marathon Brawler*)**: All-weather white polo T-shirt, cargo trousers, and Padyatra Baton.
- **True Tekken 7 Combat Mechanics**:
  - 18 moves per fighter with frame data (`HIGH`, `MID`, `LOW`, and `THROW` hit levels).
  - **Sky Launchers (`df+2` / `uf+4`)**, airborne **Juggle Combos**, and **Screw / Tailspin** extenders.
  - **3D Sidestep Evasion (`Q` / `E`)** into the Z-axis.
  - **Power Crush Armor & Rage Arts (`H`)** when HP drops below 28%, complete with slow-motion camera zoom and comic callout bubbles!
- **3 Iconic 3D Stages**:
  - *Sansad Akhada* (Grand Parliament Dome & Red Sandstone Courtyard)
  - *Howrah Bridge Nights* (Hooghly Riverfront, Cantilever Bridge & Yellow Kolkata Taxis)
  - *9 PM Breaking News Studio* ("THE NATION WANTS TO KNOW" LED Debate Arena)
- **4 Game Modes**:
  - **Arcade Tournament Ladder**
  - **1P vs CPU (Election Clash)**
  - **Local 2-Player Versus**
  - **Practice & Frame Lab** (with live frame advantage HUD and dummy behavior toggle)

## 🎮 Controls

| Action | Player 1 (Keyboard) | Player 2 (Local 2P) |
| :--- | :--- | :--- |
| **Move / Crouch / Jump** | `W`, `A`, `S`, `D` | `Arrow Keys` |
| **3D Sidestep** | `Q` / `E` | `Numpad 7` / `Numpad 9` |
| **Left Punch (`1`) / Right Punch (`2`)** | `U` / `I` (or `J` / `K`) | `Numpad 4` / `Numpad 5` |
| **Left Kick (`3`) / Right Kick (`4`)** | `O` / `P` (or `L` / `;`) | `Numpad 1` / `Numpad 2` |
| **Sky Launcher (`df+2`)** | `S + D + I` | `Down + Forward + Num5` |
| **Low Sweep (`d+3`)** | `S + O` | `Down + Num1` |
| **Hopkick Launcher (`uf+4`)** | `W + P` | `Up + Num2` |
| **Command Throw (`1+3`)** | `G` | `Numpad 6` |
| **Power Crush Armor / Rage Art** | `H` or `Space` | `Numpad 3` |
